Navigation

Moving through the file system

pwd
Print Working Directory — shows your current location in the file system
pwd
Returns: /home/student
ls
List directory contents — see what files and folders exist
ls [options] [path]
ls — current dir   ls -la — detailed + hidden
cd
Change Directory — navigate to a different folder
cd [directory]
cd .. — parent   cd ~ — home   cd / — root
🔧

File Management

Creating, moving, and deleting files

touch
Create an empty file or update file timestamps
touch [filename]
touch notes.txt — creates notes.txt
mkdir
Make Directory — create a new folder
mkdir [directory]
mkdir projects — creates projects/
cp
Copy files or directories to a new location
cp [source] [destination]
cp file.txt backup.txt   cp -r dir/ newdir/
mv
Move or rename files and directories
mv [source] [destination]
mv old.txt new.txt — rename   mv file.txt dir/ — move
rm
Remove files or directories (use with caution!)
rm [options] [file]
rm file.txt   rm -r folder/ — recursive
rmdir
Remove empty directories only
rmdir [directory]
rmdir empty_folder
👁

File Viewing

Reading and inspecting file contents

cat
Concatenate and display file contents
cat [filename]
cat readme.txt — display entire file
head
Display the first lines of a file (default: 10)
head [options] [file]
head -n 5 file.txt — first 5 lines
tail
Display the last lines of a file (default: 10)
tail [options] [file]
tail -n 5 file.txt — last 5 lines
echo
Display text or write to files
echo [text]
echo "Hello"   echo $HOME
